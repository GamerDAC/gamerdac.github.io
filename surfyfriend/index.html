FILES, SHARES & WEB PAGES

What are we grabbing?

Paste a direct file link or a supported public cloud share. Website homepages and HTML pages download as files when the server can read them. To find files linked from a public webpage, use the scanner below.

↗

Use a direct file URL or a supported Google Drive, Dropbox, or OneDrive share. A share may open its provider page first.

✦

How it works

  1. 1

    Paste a file link or supported cloud share.

  2. 2

    Choose a name, or keep the original.

  3. 3

    Direct files download; HTML pages save as files when possible.

Cloud shares may open a preview. Use the provider's own Download option if shown; sign-in and sharing permissions still apply.

⌕

Find downloadable links on a webpage

Paste a public page address to find file links it exposes. The site must allow your browser to read the page.

Scanning happens in your browser, without sending the page through SurfyFriend's server. Some sites block this kind of access; no sign-in, paywall, or stream protection is bypassed.

OPTIONAL PERSONALIZED PICKS

Ask Puter AI for website ideas

Puter can suggest sites from SurfyFriend's list and sites beyond it. SurfyFriend sends your selected topic and the built-in list, but not your download history, queue, or entered links. Puter may ask you to sign in, and its user-pays model can use your account's allowance or billing.

Puter uses its existing knowledge, not a live web search. Suggestions outside SurfyFriend's curated list are unverified; check the site, address, license, and download rules before using them. Only HTTPS links are shown. Puter requires an http:// or https:// page, not a file opened directly. About Puter.js

Use official options: This page suggests places to find openly available or official downloads. Licenses and permissions vary by item. SurfyFriend does not download protected social-media streams or content you do not have permission to access.

To enable uploads, run python3 server.py from the SurfyFriend project folder, then open http://127.0.0.1:8765/. Files stay in ~/.dropzone/uploads on this computer.

⌁Optional: same-network sharing

Off by default. Restart the server with python3 server.py --lan from the SurfyFriend project folder to let devices on your Wi-Fi/LAN access this file shelf.

Without a password or encryption, anyone on that network can view, upload, download, and delete files in this shelf. Only enable this on a trusted network; never expose the port to the internet.

Passwords are stored as salted, slow hashes; account sessions use secure cookies over HTTPS. Account data contains website addresses and download history, which may be private. Only create an account on a SurfyFriend server you trust. Hosted use requires an HTTPS reverse proxy and persistent server storage.
